# ✋ Hand Gesture Recognition using OpenCV & MediaPipe

This project detects real-time hand gestures using a webcam. It uses MediaPipe for hand landmark detection and applies custom logic to recognize multiple single-hand and two-hand gestures.

---

## 🚀 Features

- Real-time hand tracking
- Detects single-hand and multi-hand gestures
- Supports 2 hands simultaneously
- Recognized gestures:

| Gesture | Symbol |
|---------|---------|
| Fist | ✊ |
| Open Palm | ✋ |
| Thumbs Up | 👍 |
| Thumbs Down | 👎 |
| Peace Sign | ✌️ |
| OK Sign | 👌 |
| Finger Point | 👉 |
| Finger Gun | 🔫 |
| Rock-Paper-Scissors | ✊ ✋ ✌️ |
| Two-Hand Cheers | 🍻 |
| Two-Hand Heart | ❤️ |
| Unknown Gesture | ❓ |
